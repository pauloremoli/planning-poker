# Creating a room

1. Open the app and choose **Create a room** on the home page.
2. Enter your name — this is what everyone else in the room will see you
   as. It's remembered in your browser, so you won't have to type it again
   next time.
3. Pick the default deck for rooms you create (see [Choosing a
   deck](./decks.md) — you can always change it later from inside the
   room).
4. Select **Create Room**.

You're dropped straight into the new room as its **host** — the only role
that starts with full control over the room (see [Roles & host
controls](./roles.md)).

## Inviting people

As host, the room screen shows an **Invite others** card with a QR code for
the room's link. Share the link directly, or have people scan the code —
handy for projecting on a screen in an in-person planning session.

![Host view with the invite QR code, round controls, and task management](./images/host.png)

Anyone with the link can join — there's no waiting room or approval step.
If you don't want someone in the room anymore, a host can [remove
them](./roles.md#removing-someone) at any time.

## The room's link never expires on its own

A room stays alive for as long as at least one person is connected to it
(browser tabs reconnecting after a brief drop still count — see
[FAQ](./faq.md#why-did-i-briefly-see-someone-as-disconnected)). Once
everyone has left, the room and all its data are discarded automatically —
there's nothing to clean up manually, and a room can't be "reopened" later.
