# Choosing a deck

A deck is just the set of cards on offer for a vote. Pick one when you
[create a room](./creating-a-room.md), or change it anytime from [round
controls](./roles.md#round-controls) — the change applies to everyone in
the room immediately.

## Presets

| Deck | Cards |
|---|---|
| **Fibonacci** *(default)* | 0, 1, 2, 3, 5, 8, 13, 21, ?, ☕ |
| **Modified Fibonacci** | 0, ½, 1, 2, 3, 5, 8, 13, 20, 40, 100, ?, ☕ |
| **T-Shirt Sizes** | XS, S, M, L, XL, XXL, ? |
| **Powers of Two** | 0, 1, 2, 4, 8, 16, 32, 64, ?, ☕ |

`?` means "I don't have enough information to estimate," and `☕` means "I
need a break." Neither counts toward the average — nor do non-numeric decks
like T-shirt sizes; the [results panel](./results.md) simply reports the
vote distribution for those.

## Custom decks

Choose **Custom…** from the deck dropdown and type your own comma-separated
values, e.g. `1, 2, 3, 5, 8, ?`. This is handy for teams with their own
convention (a stripped-down scale, a different "unsure" symbol, and so on).

## Remembered per browser

Your last-used deck is remembered locally in your browser and reused as the
default the next time you create a room — it doesn't affect anyone else's
device, and it doesn't change a deck already in use in a room you join.
