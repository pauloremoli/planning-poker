# Voting a round

While a round is open, the **Pick a card** panel shows every value in the
room's current deck. Select a card to cast your vote — select it again (or
another card) to change your mind any time before the round is revealed.

![A voting round in progress, with participants shown as waiting or voted](./images/voting.png)

Everyone else just sees *that* you've voted, not *what* you voted — cards
stay hidden until the round is revealed. The [participant
list](./roles.md) shows who's still waiting and who's voted in, at a
glance.

## Revealing

Votes are revealed either:

- **Automatically** — by default, 2 seconds after every active (non-spectator)
  participant has voted. A host or admin can turn this off in [round
  controls](./roles.md#round-controls) if your team prefers to reveal
  manually.
- **Manually** — a host or admin selects **Reveal votes** at any time, even
  before everyone's voted.

Once revealed, see [Reading the results](./results.md). To estimate the
same task again, a host or admin can select **Vote again**, which clears
everyone's cards without changing which task is active.

## If you don't want to vote

Toggle **Spectator** instead of picking a card — see [Spectator
mode](./spectator-mode.md).
