# Spectator mode

Not everyone in a planning session needs to vote — an observer, a manager
sitting in, or someone just listening in on the discussion can step back
without leaving the room.

From the **Pick a card** panel, select **Spectator** to stop voting. Your
name moves to the **Spectators** group in the participant list, and:

- You won't be asked to vote, and any in-progress vote you had is cleared.
- You're excluded from the "has everyone voted?" check, so your presence
  never blocks [auto-reveal](./voting.md#revealing) or holds up the round.
- You can still see the current task, the live participant list, and
  results once revealed.

Select **Join voting** at any time to rejoin the active vote for the current
round.

Spectator status is a self-service toggle — it doesn't change your role, so
a host or admin who becomes a spectator keeps their round/task controls.
