# Joining a room

Open the link someone shared with you (or scan their QR code). If you
haven't set a name in this browser before, you'll be asked for one — enter
it and select **Join**.

You'll land in the room as a regular **member**: you can vote and see
results, but round and task management are reserved for the
[host or an admin](./roles.md).

## Reconnecting

If you reload the page, close the tab by accident, or your connection
drops briefly, reopening the same link resumes your seat automatically —
same name, same role, same vote if you'd already cast one. You won't be
asked to rejoin, and you won't show up as a duplicate participant. See
[FAQ](./faq.md#why-did-i-briefly-see-someone-as-disconnected) for what
other participants see while this happens.

## "Room not found"

If the link is wrong, or the room has already been closed (everyone left
it), you'll see a room-not-found message. Double check the link, or ask
whoever shared it to send a fresh one.
